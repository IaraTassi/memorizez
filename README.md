# MEMORIZEZ

Sistema de estudo com cartões e revisão espaçada, desenvolvido como projeto acadêmico do curso de **Análise e Desenvolvimento de Sistemas** da **Universidade Luterana do Brasil - ULBRA**.

## Sobre o projeto

O MemorizeZ tem como objetivo auxiliar estudantes na organização e revisão de conteúdos por meio de cartões de estudo, oferecendo uma experiência simples e prática para estudar e acompanhar revisões.

## Principais funcionalidades

- Criação e organização de coleções de cartões;
- Revisão com intervalos programados;
- Modo de Estudo Livre;
- Histórico de estudos e revisões;
- Gerenciamento de cartões e coleções.
